# Beneficiary-Update

## Development

Install dependencies with:

```bash
npm install
```

Run the application:

```bash
npm run dev
```

## Quality checks

Run the complete local verification:

```bash
npm run check
```

This runs linting, the automated test suite, and the production build.

### Tests

Run tests once:

```bash
npm test
```

Run tests in watch mode while developing:

```bash
npm run test:watch
```

Tests are located under `tests/` and reusable form/API helpers are organized under `src/utils/`.
